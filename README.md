Features
Team Management – Easily create and manage teams using /fk team.
Unlimited Teams – Create as many teams as needed.
Game Configuration – Customize game settings using /fk settings.
Multiple Maps – Use multiple maps on the same server.
Map Voting – Let players vote for the next map using /fk map.
Automatic Map Cloning – Each game starts with a fresh copy, preserving the original map.
Automatic Loot Room – Automatically generate the loot room.
Customizable KOTH System – Configure King of the Hill events using /fk koth.
Utility Commands – Additional commands to simplify server management.
Commands
Command	Description
/fk team	Open the team management menu.
/fk settings	Open the game settings menu.
/fk map	Open the map selection and voting menu.
/fk koth	Open the KOTH configuration menu.
/heal	Restore health.
/feed	Restore hunger.
/gmc	Switch to Creative mode.
/fk item rename	Rename the held item.
/fk item enchant	Enchant the held item.
Adding Custom Maps
Upload your map – Place your map folder in the root directory of your Minecraft server.
Configure the maps – Open plugins/Tr0NFK/maps.yml.
Register your map – Add the name of your map folder to maps.yml.
Done! Your map is now available in the plugin.

Important: Map folders must be placed directly in the server's root directory.
