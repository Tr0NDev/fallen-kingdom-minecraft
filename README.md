Features

Fallen Kingdom – Tr0N comes with a wide range of features designed to make managing your games easier.

Team Management – Easily create, manage and configure teams using /fk team.
Unlimited Teams – Create as many teams as your game requires.
Game Configuration – Customize your game settings through the /fk settings menu.
Multiple Maps – Use multiple Fallen Kingdom maps on a single server.
Map Voting – Let players choose the next map using /fk map.
Automatic Map Cloning – Every game starts with a fresh copy of the selected map, keeping the original map untouched.
Automatic Loot Room – Automatically generate the loot room.
Customizable KOTH System – Create and configure King of the Hill events using /fk koth.
Utility Commands – Access useful commands to simplify server administration.

And much more!

Commands
Command	Description
/fk team	Open the team management menu.
/fk settings	Open the game settings menu.
/fk map	Open the map selection and voting menu.
/fk koth	Open the KOTH configuration menu.
/heal	Restore your health.
/feed	Restore your hunger.
/gmc	Switch to Creative mode.
/fk item rename	Rename the item you're holding.
/fk item enchant	Enchant the item you're holding.

Additional commands and features are available in-game.

Adding Custom Maps

Want to use your own Fallen Kingdom maps? Follow these simple steps.

1. Upload your map

Place your map folder in the root directory of your Minecraft server.

2. Configure the maps

Open the following configuration file:

text
/plugins/Tr0NFK/maps.yml


3. Register your map

Add the name of your map folder to maps.yml.

4. You're ready!

Your map will now be available for use through the plugin.

Note: Make sure the map folder is placed directly in the server root directory.
